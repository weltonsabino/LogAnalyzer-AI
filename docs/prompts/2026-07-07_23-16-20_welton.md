## Prompt original

Quero organizar o versionamento inicial do projeto.Execute as seguintes ações:1. Crie uma branch `develop` a partir da `main`.2. Faça o checkout para a branch `develop`.3. Adicione todos os arquivos atuais ao controle de versão.4. Utilize os hooks configurados no projeto durante o processo de commit.5. Crie um commit seguindo o padrão Conventional Commits, representando toda a preparação inicial do projeto (estrutura, documentação, hooks, issues, configurações iniciais, Kanban etc.).6. Faça o push da branch `develop` para o repositório remoto.7. Abra um Pull Request da branch `develop` para a `main`.Considere que, até este momento, o projeto contém apenas a preparação inicial, incluindo:- Estrutura inicial do repositório;- Documentação;- Hooks do Git;- Configurações do projeto;- GitHub Issues;- GitHub Projects (Kanban);- Demais arquivos necessários para iniciar o desenvolvimento.A descrição do Pull Request deve conter:- Um resumo das atividades realizadas;- O objetivo desta preparação inicial;- Uma observação informando que ainda não há funcionalidades implementadas, apenas a estrutura base do projeto.Utilize uma mensagem de commit clara e seguindo o padrão Conventional Commits.
